# Image assets

Drop real assets here using the **exact filenames below** and they will
automatically replace the labelled placeholders on the site. Until a file
exists, a branded placeholder with the filename is shown — nothing breaks.

All paths are referenced from `src/content.ts`.

| Filename | Where it appears | Recommended shot |
|---|---|---|
| `founder-hero.jpg` | Hero + Founder section | Founder portrait or vertical video poster (4:5, ~1200×1500) |
| `app-home.png` | (optional) app home screen | Phone screenshot, 9:19 |
| `meal-analysis.png` | Features → Meal analysis | Verdict / analysis screen, 9:19 |
| `smart-swaps.png` | Features → Smart swaps | Swap suggestion screen, 9:19 |
| `meal-plan.png` | Features → Meal plan generator | 1–7 day plan screen, 9:19 |
| `grocery-list.png` | Features → Grocery list | Shopping list screen, 9:19 |
| `real-life-notes.png` | Features → Real-life notes | Notes / preferences screen, 9:19 |
| `progress.png` | Features → Progress & coaching | Progress / trends screen, 9:19 |
| `before-after-1.jpg` … `-3.jpg` | Results transformations | Client before/after (3:4) |
| `dm-1.png` … `dm-3.png` | Results DM proof | Screenshots of real DMs (9:13) |
| `testimonials.png` | (reserved) | Optional testimonial collage |

Tips:
- Phone screenshots look best at a 9:19 aspect ratio (e.g. 1170×2532 iPhone).
- Keep founder/before-after images vertical for the layout.
- Always get written permission before using client transformation photos or DMs.
